# 2026-05-15 工作记录

## A股恐慌看板 — 实现完成

### 已完成
1. **config.json** — 配置文件，含 Tushare token、飞书 webhook、阈值参数
2. **state.json** — 防重复告警状态文件
3. **history.json** — 恐慌事件历史记录（空数组初始化）
4. **panic_monitor.py** — 核心监控脚本
   - 使用 Tushare Pro API 获取沪深300数据、全A股数据
   - 三个触发条件（跌幅、量比、普跌）同时满足才告警
   - 恐慌分级：一级（2.5~2.9%）、二级（3.0~3.9% 且 PE-TTM≤13）、三级（≥4.0%）
   - 飞书告警（每次交易日同级别只告警一次）
   - 量比计算结果缓存到 `volume_cache.json`（当天有效）
   - 历史图表数据缓存到 `history_cache.json`（当天有效）
   - 更新 `panic_dashboard.html` 中的 SNAP 数据对象
5. **panic_dashboard.html** — 可视化看板
   - 暗色主题，单文件，Chart.js 4.4.0
   - KPI 卡片（恐慌级别、沪深300涨跌幅、全A股下跌占比）
   - 三大条件面板（进度条 + 状态指示）
   - 历史图表（最近60日跌幅折线 + 恐慌区间色带标注）
   - 告警历史表格
6. **run_panic_check.bat** — 计划任务执行脚本
7. **注册计划任务.bat** — 需要管理员权限运行，注册每日16:00自动执行

### 关键技术细节
- `index_daily` 成交量字段是 `vol`（手），不是 `volume`
- `get_volume_ratio()` 首次运行需回溯21个交易日，很慢（~80秒），已加缓存机制
- 历史图表数据 `build_history_chart_data()` 需60次 API 调用，已加缓存机制
- 防重复告警：`state.json` 按日期 + 级别去重
